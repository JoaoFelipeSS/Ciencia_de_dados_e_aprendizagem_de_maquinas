## 2. Visão geral

### 2.1 Resumo do projeto

O projeto propõe analisar a usabilidade e a acessibilidade de portais governamentais municipais para identificar possíveis barreiras enfrentadas por usuários idosos. Serão observados aspectos como navegação, legibilidade, contraste, organização, clareza das informações e recursos de acessibilidade. A análise será realizada com base em critérios da WCAG 2.1, eMAG 3.1 e princípios de usabilidade. Como resultado, espera-se organizar os dados coletados, comparar os portais analisados e identificar oportunidades de melhoria que possam contribuir para uma experiência de uso mais acessível e adequada ao público idoso.

### 8.1 Avaliação inicial dos dados

- **Disponibilidade:** Os portais governamentais são acessíveis publicamente pela internet, permitindo a realização da análise das interfaces.
- **Volume e período coberto:** A análise será realizada sobre os portais municipais selecionados durante o período definido para o projeto.
- **Dados ausentes, duplicados ou inconsistentes previstos:** Podem ocorrer informações indisponíveis em determinadas páginas ou diferenças na estrutura dos portais. Essas situações serão registradas durante a coleta.
- **Necessidade de integração entre fontes:** Será necessário relacionar os dados coletados nos portais com os critérios definidos a partir da WCAG 2.1 e do eMAG 3.1.
- **Restrições legais, contratuais ou institucionais:** O projeto utilizará informações disponíveis publicamente nos portais, evitando coleta desnecessária de dados pessoais.

- [ ] Dados pessoais serão minimizados, anonimizados ou pseudonimizados quando necessário.

**Cuidados específicos deste projeto:**

A pesquisa terá como foco a análise das interfaces e dos recursos disponíveis nos portais públicos. Não será necessária a coleta de dados pessoais de usuários para a realização da avaliação. Quando houver necessidade de registrar evidências, serão priorizadas informações relacionadas à própria interface e ao funcionamento público dos portais.
